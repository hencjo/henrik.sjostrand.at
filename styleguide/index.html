The problem

Body text is set at a comfortable size with generous leading and a measure of roughly 68 characters, so long paragraphs stay easy to follow. Links look like this, strong text stands out a little, emphasis is plain italic, and inline code such as jix.lock or --force sits on a quiet tint. Keys: Ctrl + C.

A second paragraph shows the spacing between paragraphs. It should feel like a page in a book, not a wall of UI.

Design choice
