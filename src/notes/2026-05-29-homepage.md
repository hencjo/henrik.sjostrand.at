The site should feel like a personal changelog / field notebook, not a portfolio.

Good constraints:

- plain text over polish
- artifacts over adjectives
- quiet competence
- semantic Markdown for anything article-shaped
- layouts and CSS as replaceable skins

The trap is making it too nice. That would be fake. Better to make it useful, legible, and slightly severe.
