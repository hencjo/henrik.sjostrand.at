## Background

Argo is a JSON parser and generator for Java without external dependencies, originally hosted on SourceForge.

## Contribution

I contributed to the library during its SourceForge period. The record is less complete than for later, GitHub-hosted work; the available references are the SourceForge and GitHub project histories and an old Rebel Alliance profile listing Argo among my open source contributions.

## Discussion

Small libraries without dependencies are a recurring preference in my work, and Argo is an early instance of it.
