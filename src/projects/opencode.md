## The project

opencode is an open source coding agent built for the terminal.

## What I did

Nix-related fixes and packaging work — the infrastructure and tooling lane.

## Why it matters

Coding agents move fast, and packaging tends to lag behind. Keeping the Nix build healthy means people can pin and run the agent like any other tool in their environment. Very on brand: make the thing easier to build and run, then get out of the way.
