Notes on tools I build and use: the problems they address and the approaches they take.

  1. Nov 06, 2026

    Introducing jix: separating dependency resolution from the Java build

    jix resolves Maven dependencies once, pins them with Nix, and lets builds be written as ordinary code.

    jix is now available: dependencies are resolved from Maven Central with Maven's semantics and pinned with Nix, so the build itself becomes a short, readable description instead of a plugin configuration.

  2. Sep 24, 2026

    Read-only agent access to a corporate Confluence

    A small setup — confluence-cli, an agent skill, and SecretSpec — for retrieving and consolidating information from an internal wiki.

    Locating reliable information in our wiki was slow, and much of it was outdated. Delegating retrieval and cross-checking to an agent, with read-only access and no exposure of credentials, reduced that cost considerably.

  3. Aug 27, 2026

    Introducing cryo: API regression tests from existing curl examples

    cryo turns curl examples already present in a codebase, and OpenAPI operations, into reviewed HTTP snapshot tests.

    cryo is now available: most codebases already contain informal API tests in the form of curl examples in documentation. cryo collects them and turns them into reviewed regression checks.

  4. Aug 06, 2026

    Introducing Fransson: reproducible Kafka topics for local and test environments

    Fransson is a one-directional tool for dumping, restoring, and cloning Kafka topics, with their partitioning and configuration intact.

    Fransson is now available: a tool for reproducing Kafka topics in local and test clusters, with matching partition counts and topic configuration, safe cloning from live sources, and dumps that restore identically.

  5. Jun 12, 2026

    Introducing stow: GitOps deployments for a single Docker host

    stow is a GitOps reconciler for Docker service deployments, with changes reviewed as merge requests and automatic convergence on the host.

    stow is now available: reviewed, auditable deployments for a plain Docker host. Changes are merge requests, and the host converges, or rolls back, without manual intervention.

  6. May 04, 2026

    Introducing Silo: a local OpenID Connect provider for development and testing

    Silo is a local-only OpenID Connect mock provider, with a browser user picker and signed tokens, for development and tests.

    Silo is now available: a complete OpenID Connect login flow on localhost, with a user picker in place of a corporate identity provider.

  7. Mar 18, 2026

    Service modules, port allocation, and process watching in devenv

    Contributions to devenv covering service modules, port allocation, process watching, and evaluation caching.

    A series of small fixes to a tool I use daily: services that start cleanly, ports that do not collide across projects, and processes that do not restart without cause.

  8. Aug 24, 2016

    Two contributions to Argo, a dependency-free JSON library for Java

    A fix for incomplete reads in Argo's position-tracking reader (2016), and buffered reading in its parser (2026).

    Two small changes, ten years apart, to a JSON library for Java with no external dependencies: one correcting how input is read, one making it faster.

  9. Feb 23, 2014

    An HTTP interface to wkhtmltopdf, in Haskell

    A small REST service around wkhtmltopdf: it accepts a URL and returns a PDF.

    A single-purpose service, written in Haskell, that accepts a URL and returns the rendered PDF.

  10. Nov 24, 2013

    An LDAP authenticator for Summer Security

    A companion library that adds LDAP authentication to Summer Security.

    Directory-based authentication added to Summer Security as a separate component, without introducing a framework.

  11. May 14, 2013

    Showing the repository-relative path in a Bash prompt

    Small Bash helpers for Git-aware prompts.

    A Bash prompt that shows the current directory relative to the repository root, which is considerably more useful in deep project trees.

  12. Jan 12, 2013

    Database migrations with an explicitly declared order

    A small Java database migration library in which migrations and their order are declared in code.

    Database migrations whose order is declared in code, rather than inferred from whichever files are found on the classpath.

  13. Dec 19, 2012

    Web authentication as an ordered list of rules in Java

    A small, dependency-free Java library that expresses web authentication as a code-first DSL.

    Authentication policy expressed as an ordered list of rules in plain Java, without XML configuration, thread-local state, or a framework.

  14. Oct 26, 2012

    Structuring a pull request for review: a jOOQ bug fix

    A fix for inserting PostgreSQL string arrays containing quotes or backslashes, later cited by the jOOQ project as an example pull request.

    A small bug fix whose structure (refactoring, then a regression test, then the fix) the jOOQ project later used as an example of a well-formed contribution.
