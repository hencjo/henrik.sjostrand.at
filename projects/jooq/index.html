jOOQ

Fix for inserting PostgreSQL string arrays containing quotes or backslashes.

In short A small bug fix that the jOOQ blog later held up as an example of how to write a good pull request.

The project

jOOQ is a type-safe SQL DSL and code generator for Java.

What I did

Fixed insertion into PostgreSQL string arrays when the strings contained " or \ characters.

The pull request was shaped deliberately: small refactoring steps first, then a regression test, then the actual fix.

Why it matters

The jOOQ blog later used it as its example in How to provide a good pull request, calling it an “awesome pull request”. The fix was small; the lesson about making changes easy to review has stuck with me since.
